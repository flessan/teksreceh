## [0.1.0] - 2026-01-01

### Added
- Rilis awal **teksreceh** 🗿
- 50+ generator dalam 9 kategori (Meme Indonesia, Tongkrongan, Gaming, Sosial Media, Developer, Fancy Text, Unicode, Utilities)
- Realtime transformer tanpa tombol generate
- Persona system: Normal, Alay 2010, Wibu, Rimsvek, Discord Mod, Emak Facebook, Bocil ML, Bocil FF, Twitter, TikTok, Jaksel
- Command palette (`Ctrl+K` / `⌘K`)
- Custom dropdown generator dengan search + grouping per kategori
- Favorite & recent history via `localStorage`
- Dark mode biru soft (bukan hitam pekat)
- PWA + offline support via service worker
- SEO: meta tag, Open Graph, Twitter Card, JSON-LD (WebApplication, BreadcrumbList, FAQPage), canonical, sitemap.xml, robots.txt
- Advanced option toggle (persona, slider, auto copy, mini lore, FAQ, history)
- Halaman `/tentang`
- Share URL (`?g=slug&q=input`)
- Neo-brutalism UI dengan palet biru cerah
